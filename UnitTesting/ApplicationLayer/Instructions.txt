1. Write Python Module for running functions from appropriate ApplicationLayer functions. 

2. Write a Test file to test the python module written in step 1. 

3. From the main project directory run command: pytest UnitTesting/ApplicationLayer/{name of test file}.py
    -Ensure pytest is installed 
    -Ensure that the test file starts with test_{}.py

Example: 

1. 'NOC_History_And_Latest.py' is module written for testing ApplicationLayer modules for the 
use case: 'As a student I want to see the historical employment trend for a NOC and I want to see the latest changes in economic regions.'

2. 'test_noc_history_and_latest.py' is pytest module that tests 'NOC_History_And_Latest.py' and saves the output and results of the test in the Results folder.

2. Command: pytest UnitTesting/ApplicationLayer/test_noc_history_and_latest.py
